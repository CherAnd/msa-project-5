## Выводы

Для текущей задачи генерации прайс-листов оптимально использовать Kubernetes CronJob, поскольку объём данных небольшой, легко интегрировать в уже существующую микросервисную инфраструктуру, простое логирование и мониторинг через стандартные K8s инструменты.


## Верхнеуровневый пошаговый план

### 1. Подготовка SQL-запроса

Написать shell-скрипт, в котором будет выполняться SQL-запрос с join по products, categories, clients, client_prices и выгрузка в объектное хранилище

```shell
psql -h "$DB_HOST" -p "$DB_PORT" -d "$DB_NAME" -U "$DB_USER" -w -v ON_ERROR_STOP=1 -f "$QUERY_FILE" -c "\copy (SELECT * FROM (${(< \"$QUERY_FILE\")}) as subquery) TO STDOUT WITH CSV HEADER" > "$OUTPUT_FILE"

aws --endpoint-url "$S3_ENDPOINT" s3 cp "$OUTPUT_FILE" "s3://${S3_BUCKET}/${S3_KEY}"
```


### 2. Упаковка в контейнер 

```Dockerfile
FROM postgres:alpine

RUN apk add --no-cache bash

WORKDIR /app

COPY run_query.sh .

RUN chmod +x run_query.sh

ENTRYPOINT ["/app/run_query.sh"]
```


### 3. Настройка K8s CronJob

Примерный CronJob для запуска контейнера ежедневно в 6:00:
```yaml
apiVersion: batch/v1
kind: CronJob
metadata:
  name: csv_exporter
spec:
  schedule: "0 6 * * *"
  jobTemplate:
    spec:
      template:
        spec:
          containers:
          - name: csv_exporter
            ...
```

### 4. Логирование и мониторинг

- Логирование контейнеров уже должно быть настроено в K8s.
- Метрики и алерты также подключаются к существующей инфраструктуре Prometheus, Grafana и т.п.
